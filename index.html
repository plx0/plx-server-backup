PLX Server Backup

A personal application that uses rclone to back up selected files from an Oracle-hosted server to the owner's Google Drive.

Operated by the GitHub user plx0. This website explains the application and its privacy practices. Backups run through the owner's rclone installation; this site has no sign-in or file-upload interface.

Why Google Drive access is needed

The intended OAuth permission is https://www.googleapis.com/auth/drive.file. It permits the application to create and manage its own backup files and folders, and files explicitly made available to the app. It does not grant general access to all files in the account.

For rclone, this scope is intended for files and folders created by the application. Existing files uploaded through another application may not be visible. The operator must configure rclone to request this scope; adding it in Google Cloud alone does not change rclone's requested permissions.

Control stays with the account owner

The owner selects backup sources and destinations and controls any schedules, retention rules, restore operations, and deletion. Disconnecting the app stops future authorized access but does not automatically remove existing backup files.

Access can be revoked in Google Account connections. Read the privacy policy for storage, sharing, retention, and deletion details.
